## 新版本内容

本版本重点修复 Windows 下大型分析任务无法启动的问题，并完善新建任务的独立配置能力和运行诊断。

### 新增与优化

- 新建分析任务时，可在“分析配置”中分别选择分析配置预设和错误容忍预设。
- 支持载入设置中保存的极速、快速、普通、精确、完美、自定义及相同文件检查配置。
- 预设载入后可继续修改全部参数；修改只应用于当前任务，不会覆盖设置中的全局预设。
- 新建、稍后运行、暂停恢复和分阶段执行都会使用任务创建时保存的完整配置。
- 增加 Python 启动诊断摘要，记录可执行文件、项目目录、参数文件和估算命令行长度，便于排查无法启动的问题。
- 分析任务启动失败时自动打开错误日志，减少无法看到命令行细节的问题。

### 修复的问题

- 修复大型任务把完整配置和大量视频路径写入 Python 启动命令，导致 Windows 报“文件名或扩展名太长 (os error 206)”的问题。
- 任务配置改由临时 JSON 文件传递，不再受 Windows 命令行长度限制；Python 放在较短目录下也不再是必要的规避方式。
- 修复 Python 尚未启动时只提示检查 Python 路径、无法判断实际为完整命令过长的问题。
- 修复任务运行时可能被当前全局设置覆盖并行数的问题。
- 修复启动已有任务时会临时改写设置页目录状态的问题，确保任务配置与全局设置相互独立。

## 下载建议

- 遇到“Python 环境不可用：文件名或扩展名太长 (os error 206)”的 Windows 用户建议优先升级本版本。
- 大多数 Windows 用户建议下载 `windows-x64-cpu-installer.exe`；NVIDIA 显卡且需要 CUDA 加速时请选择 `windows-x64-gpu-installer.exe`。
- 不希望安装时可下载对应的 `portable.zip` 便携版，解压后直接运行。
- `.sig`、`latest.json` 等文件用于自动更新和签名校验，普通用户无需单独下载。
