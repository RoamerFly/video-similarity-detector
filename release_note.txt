## v1.3.1 新版本内容

本版本主要完善运行环境更新机制、视频合并导出、侧边栏任务状态、报告管理与界面布局，并修复多个可能影响日常使用的问题。

### 一、运行环境检测与更新

- AI 运行环境、离线 CLIP 模型和视频合并环境的操作按钮统一为“重装/更新环境”。
- 点击按钮后，先根据 GitHub 最新环境清单、资源哈希和模型文件哈希判断当前环境是否需要更新，不再根据应用版本号判断。
- 检测到新环境时，可直接更新；当前已经是最新版时，会再次询问是否强制重装。
- 修复离线 CLIP 模型在“正在解压并校验模型”阶段可能导致程序闪退的问题。
- 三种环境安装完成后均会显示明确的完成提示。
- 每次启动程序时自动检测 Python、CLIP、FFmpeg、GPU 等环境状态。
- 环境状态使用紧凑单行布局显示，正常状态显示为绿色，异常状态显示为红色。
- 修复重置设置后环境检测结果消失的问题。
- 每次启动时在后台自动检查应用更新；发现新版本时弹窗提示，没有更新时不打扰用户。

### 二、视频合并与导出

- 修复合并来自不同目录的视频时，出现“最终输出目录无效：函数不正确（os error 1）”的问题。
- “使用源文件夹”和“浏览选择文件夹”现在可以正常选择。
- 当视频来自多个源文件夹时，“导出文件夹路径”会显示为下拉框，可选择其中任意一个源目录。
- 默认使用第一个视频片段所在的源文件夹。
- 修复时间线标题被截断成省略号的问题。
- 增加常驻的导出状态胶囊，可以查看导出进度、状态和实时日志。

### 三、分析与导出状态胶囊

- 分析任务和视频导出的状态胶囊移动到左侧导航栏底部，并在各页面常驻显示。
- 两个胶囊不能同时展开，展开一个时会自动收起另一个。
- 分析过程中显示“分析 XX%”，导出过程中显示“导出 XX%”，避免进度归属不明确。
- 折叠状态下增加暂停或继续按钮，减少操作步骤。
- 修复暂停后删除任务，胶囊仍停留在“已暂停”状态的问题。
- 调整展开与折叠箭头方向，并统一两个胶囊的箭头位置。
- 统一分析和导出日志面板的尺寸，缩短展开高度并减小日志标题字体。
- 缩小折叠胶囊宽度和胶囊间距，使侧边栏底部布局更加紧凑。
- 版本号改为无边框纯文本，紧邻两个状态胶囊并固定在导航栏底部。

### 四、报告与比较结果管理

- 修复同一批视频使用不同分析配置时，报告列表可能互相覆盖或只显示最后一个报告的问题。
- 报告现在按照完整报告路径区分和选择，不同配置生成的报告可以分别保留。
- 优化报告列表刷新和自动选择逻辑，进入结果页面时能够及时显示新生成的报告。
- 在对比视图中删除视频文件时，会同步触发“删除与该视频相关记录”，避免报告中残留无效结果。
- 修复结果总览页面“每页 XX 条”下拉框背景与文字颜色冲突的问题。
- 缩小报告目录、分页栏与上下区域的间距，让表格能够显示更多内容。
- 删除结果总览左上角重复的“共分析 XX 个视频，生成 XX 对比较结果”提示。

### 五、分析任务页面布局

- 分析任务卡片与页面标签之间的间距缩短为 1px。
- 运行状态卡片与分析任务卡片之间的间距缩短为 1px。
- 放大任务列表页面标题，并与分析任务页面标题保持一致。
- 实时日志入口改为与视频合并页面一致的悬浮状态胶囊。

### 六、多语言与界面修复

- 补充设置、环境管理、任务状态、报告管理和视频合并页面中遗漏的英文翻译。
- 优化英文状态下环境检测文本布局，避免文字截断、交叉或重叠。
- 统一中英文环境状态、按钮和进度提示的显示方式。
- 调整侧边栏底部胶囊、箭头和版本号的对齐与间距。

### 七、升级兼容性

- 从 v1.3.0 升级到 v1.3.1，通常不需要重新安装 AI 运行环境、CLIP 模型或 FFmpeg。
- 程序会根据环境文件和模型的实际哈希判断是否需要更新。
- 如果检测结果显示环境已是最新版，可以继续使用现有环境；只有环境损坏或用户希望重新安装时才需要强制重装。
- 本次升级不会删除已有视频、分析报告、设置和特征缓存。

## 下载建议

普通用户只需要下载一个与系统对应的应用包：

- Windows CPU 安装版：`Video_Similarity-v1.3.1-windows-x64-cpu-installer.exe`
- Windows GPU 安装版：`Video_Similarity-v1.3.1-windows-x64-gpu-installer.exe`
- macOS M 系列：`Video_Similarity-v1.3.1-macos-arm64-installer.dmg`
- macOS Intel：`Video_Similarity-v1.3.1-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：`Video_Similarity-v1.3.1-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：`Video_Similarity-v1.3.1-linux-x64-installer.rpm`

不想安装时，可以选择对应平台文件名中带有 `portable` 的便携包，解压后直接运行。
