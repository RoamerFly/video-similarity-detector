## v1.2.0 新版本内容

本版本重点提升大批量视频下的识别性能与内存占用、重写合并编辑器、全面修复任务执行与报告查看过程中的卡顿，并修复一系列页面显示与数据明细问题。

### 一、性能与稳定性（重点）

1. 彻底解决任务执行期间卡顿、无法切换页面
- 后端 emit_progress_detail 全局 100ms 节流，覆盖 Python 逐帧回报与 Rust 原生指纹判重两条路径，始终放行最终进度与 ≥1% 的明显跳变。
- 前端日志在 store 内按 200ms 批量合并刷新，逐视频日志洪峰收敛为低频状态更新。
- 已扫描视频列表抽为 React.memo 组件，进度/日志更新不再重建数千行列表。5572 个视频规模下主线程不再饱和。

2. 报告读取与对比视图不再卡死
- Tauri 侧报告读取改为 async + spawn_blocking，磁盘读取与 JSON 解析在阻塞线程池执行，主线程始终响应。
- 结果页进入时不再自动读取大报告，下拉框显示「选择报告文件」，仅任务完成时自动读取本次报告（路由 state 标记 autoLoadReport）。
- 对比视图只读取内存中 selectedPair.frameMatches，绝不重新读盘/重新解析报告。

3. 启动优化
- 路由 chunk 预热：启动后空闲 150ms 后台预加载结果页/对比页/合并页/设置页，首次切换页面变瞬时。

### 二、识别引擎（Python）升级

- 候选筛选多尺度草图 + LSH 签名索引：新增辅助签名索引（phash/simhash），做廉价 LSH 预筛，配合时间轴辅助打分，候选更准更快。
- 流式嵌入管线：嵌入分 batch 流式计算并复用帧缓存，替代整段一次性嵌入；支持可选半精度（fp16）CUDA 推理，显存占用大幅下降。
- 资源池按需加载（新增 resource_pool.py）：模型/索引按需加载释放，避免常驻占用内存。
- 方向感知分段聚合：分段器加入在线仿射趋势拟合，双向（A→B / B→A）分段分别聚合、融合去重，包含/被包含关系判定更准确。
- 运行指标（新增 metrics.py）：记录各阶段内存峰值（psutil/Windows）、CUDA 显存快照，便于排查资源占用。
- 帧缓存 schema v3→v4：旧缓存自动失效重建。
- FAISS 线程预算配置：按 CPU 数自动配置线程数。

### 三、合并编辑器重构

- 单文件 MergePage.tsx 拆分为 20+ 职责模块（时间轴/预览/播放/交互/草稿等），新增 useTimelineInteractions、MergeTimeline、MergePreviewCanvas、PreviewEditDraft、MediaSeekCoordinator、playbackPolicy、timelineLayout 等，配套 12 个单测。
- 时间轴虚拟化渲染 + 自适应宽度：大量片段时不卡。
- 高级设置对话框：MergeAdvancedSettingsDialog 独立配置输出参数。
- 预览编辑草稿交互：预览区的编辑操作先落草稿、可撤销/提交。
- 全页面统一紧凑页头：结果/对比/合并/设置页去除副标题，页头更紧凑。

### 四、界面与交互改进

- 设置页「重置」按钮改为文字按钮，点击弹出确认提示（按页签显示对应文案），确认后才执行恢复默认，避免误触。
- 首次运行/环境下载对话框新增「网络代理」输入框：下载运行环境前先保存代理设置，后续检查更新、模型下载沿用。
- 结果页分页优化：默认每页 20 条（原 10），新增 100 条档位，页码改纯数字按钮 + 紧凑分页栏，表格获得更多可视空间；对比页改块级流式布局，修复视频预览面板被压缩重叠问题。
- 修复近重复对相似帧明细丢失：余弦相似度 float32 精度残留（如 1.0000002）被误判为 0.01 百分比，导致「当前报告没有相似帧明细」。现收敛到 1，68544 对帧匹配正常显示 480 条明细。
- 日志本地化：运行、扫描、索引、比较、报告等阶段的用户可见日志统一为「中文(English)」双语输出，中英文用户均可直接阅读；供前端解析的机器协议行（如 ANALYSIS_VIDEO_QUARANTINED）保持英文不变。
- 英文翻译收尾：修正 What's New、full workflow、fine-tune、Elapsed Time、Managed env 等用词；区分「关闭窗口(Close Window)」与开关「关闭(Off)」；补齐网络代理、模型安装/重装、全选报告、播放器错误提示等此前缺失的英文。

### 五、修复的问题汇总

- 删除报告不生效（改用应用内两步确认，window.confirm 在 Tauri 2 静默失效）
- 结果总览与对比页底部截断、无法滚动
- 新建任务重复扫描整个视频目录（目录未变化时复用扫描结果）
- 任务执行期间卡顿、无法切换页面
- 进入结果页即解析大报告卡顿
- 对比视图重复读取报告卡死
- 修复界面英文折行：分析任务页「Create Task」等按钮折成两行浪费空间、设置页长英文参数标签折行而非省略、结果页分页与对比页「回到该帧」按钮在窄布局下折行，现均改为单行显示。

## 下载建议

普通用户只需要下载一个与系统对应的应用包：

- Windows CPU 安装版（推荐大多数用户）：`Video_Similarity-v1.2.0-windows-x64-cpu-installer.exe`
- Windows GPU 安装版：`Video_Similarity-v1.2.0-windows-x64-gpu-installer.exe`
- macOS M 系列：`Video_Similarity-v1.2.0-macos-arm64-installer.dmg`
- macOS Intel：`Video_Similarity-v1.2.0-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：`Video_Similarity-v1.2.0-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：`Video_Similarity-v1.2.0-linux-x64-installer.rpm`

不想安装时，可以选择同平台文件名中带 `portable` 的便携包，解压后直接运行。
