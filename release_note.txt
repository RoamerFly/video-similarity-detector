## v1.2.0 新版本内容

本版本重构了视频合并编辑器，统一了所有页面的界面布局，并对后端候选筛选、嵌入与分段算法做了大幅性能与内存优化。

### 新增与优化

- 重构视频合并编辑器：将合并页面拆分为时间轴、预览、交互、草稿等职责清晰的模块，并新增时间轴虚拟化渲染与自适应宽度，超长时间轴下滚动更流畅。
- 新增「高级设置」对话框：视频编码器、码率控制、恒定质量、编码速度、音频码率、两遍编码、画面适配与空余区域等选项集中管理。
- 预览画布按输出宽高比自适应缩放；播放时自动校正音画漂移；快速拖动时间轴时合并寻址请求，交互更跟手。
- 拖动、裁剪与布局调整改为独立草稿实时预览，松手后才提交；空轨道自动隐藏，界面更简洁。
- 所有页面统一为紧凑页头，logo 与标题缩小、去除冗余副标题，切换页面时共享元素位置保持一致、不再跳动。
- 修复多处文字重叠与超限：长路径、表格与日志文本自动截断或换行，不再撑破布局。
- 候选视频筛选重写：采用多尺度草图与辅助签名索引，短片段与多次复用片段的召回更准，同时大幅降低内存占用。
- 嵌入改为流式管线，按批处理帧数据；新增可选半精度 CUDA 推理（环境变量开启），显存不足时自动降级。
- 精比较阶段引入资源池按需加载，不再一次性把所有视频的索引驻留内存；FAISS 按比较 worker 数分配线程，避免线程竞争。
- 分段聚合改为方向感知的双向融合，并加入时间斜率一致性校验，识别结果更准确。
- 分析报告新增分阶段耗时与内存峰值等运行指标。

### 修复的问题

- 修复时间上相隔很远但偏移相同的重复片段被错误合并的问题。
- 修复稀疏动态采样下覆盖率统计失真的问题，改为基于真实时间线的时长覆盖。
- 修复解码器回调失败时的 fallback 逻辑，避免重复或丢失帧。
- 修复候选筛选多线程下的排序抖动，保证结果稳定可复现。

### 兼容性说明

- 帧特征缓存格式升级，旧版缓存会在首次分析时自动失效并重新生成，属预期行为。
- 报告 JSON 新增 metrics 字段，对旧版本为增量变更，不影响既有字段。

## 下载建议

普通用户只需要下载一个与系统对应的应用包：

- Windows CPU 安装版（推荐大多数用户）：`Video_Similarity-v1.2.0-windows-x64-cpu-installer.exe`
- Windows GPU 安装版：`Video_Similarity-v1.2.0-windows-x64-gpu-installer.exe`
- macOS M 系列：`Video_Similarity-v1.2.0-macos-arm64-installer.dmg`
- macOS Intel：`Video_Similarity-v1.2.0-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：`Video_Similarity-v1.2.0-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：`Video_Similarity-v1.2.0-linux-x64-installer.rpm`

不想安装时，可以选择同平台文件名中带 `portable` 的便携包，解压后直接运行。

以上安装包和便携包都是轻量应用包，不再内置大型 AI 环境。Windows 新用户第一次启动时，应用会把对应 runtime 安装到所选目录的 `env`：CPU 版通常为数百 MB，GPU 版接近 2 GiB；第一次分析还会把约 600 MB 的 CLIP 模型安装到同一目录的 `models`。旧用户原有的 `env` 和 `models` 会直接复用。

从 v1.1.0 开始，如果后续只是新增按钮、修改合并视频页面、修复界面或业务逻辑，更新程序只下载十几至几十 MB 的应用更新，原有 runtime 和模型会继续使用。只有 runtime 或模型版本确实改变时，才会重新下载对应资产。

`Video_Similarity-runtime-v1-*`、`.sha256`、`*-updater.exe`、`.sig` 和更新 JSON 均由应用自动选择、下载或校验，普通用户不需要手动下载。

Windows GPU runtime 使用 CUDA 13.0，仅适用于 Turing 或更新架构（计算能力 7.5+）且安装 R580+ 驱动的 NVIDIA 显卡。其他设备请选择 CPU 包，避免无效下载。
