## v1.2.1 新版本内容

本版本为维护更新，修复了任务执行期间界面卡顿、无法切换页面、部分页面底部内容被截断无法滚动，以及删除报告不生效、进入结果页卡顿等问题。

### 修复的问题

- 修复任务执行期间界面卡顿、无法切换页面的问题：比较阶段逐帧回报进度导致前端高频整页重渲染，现已按时间节流回报进度，并始终放行明显跳变与最终进度。
- 修复结果总览页「比较结果」子页面底部被截断的问题：分页按钮与结果表格现可正常滚动查看。
- 修复相似帧对比页与相同文件对比页底部被截断、无法滚动查看更多内容的问题。
- 修复「新建任务」每次都重新扫描整个视频目录的问题：视频目录未变化时直接复用已有扫描结果。
- 修复「删除报告」不弹确认且未真正删除文件的问题：改为应用内两步确认后再删除对应报告文件。
- 修复进入结果页即解析大报告导致卡顿的问题：初始不再自动读取报告，下拉框显示「选择报告文件」，仅任务完成时自动读取本次任务生成的报告。
- 修复对比视图重复读取报告文件导致卡死的问题：对比页现在只读取内存中的帧匹配结果，不再重新解析报告。

## 下载建议

普通用户只需要下载一个与系统对应的应用包：

- Windows CPU 安装版（推荐大多数用户）：`Video_Similarity-v1.2.1-windows-x64-cpu-installer.exe`
- Windows GPU 安装版：`Video_Similarity-v1.2.1-windows-x64-gpu-installer.exe`
- macOS M 系列：`Video_Similarity-v1.2.1-macos-arm64-installer.dmg`
- macOS Intel：`Video_Similarity-v1.2.1-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：`Video_Similarity-v1.2.1-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：`Video_Similarity-v1.2.1-linux-x64-installer.rpm`

不想安装时，可以选择同平台文件名中带 `portable` 的便携包，解压后直接运行。

以上安装包和便携包都是轻量应用包，不再内置大型 AI 环境。Windows 新用户第一次启动时，应用会把对应 runtime 安装到所选目录的 `env`：CPU 版通常为数百 MB，GPU 版接近 2 GiB；第一次分析还会把约 600 MB 的 CLIP 模型安装到同一目录的 `models`。旧用户原有的 `env` 和 `models` 会直接复用。

从 v1.1.0 开始，如果后续只是新增按钮、修改合并视频页面、修复界面或业务逻辑，更新程序只下载十几至几十 MB 的应用更新，原有 runtime 和模型会继续使用。只有 runtime 或模型版本确实改变时，才会重新下载对应资产。

`Video_Similarity-runtime-v1-*`、`.sha256`、`*-updater.exe`、`.sig` 和更新 JSON 均由应用自动选择、下载或校验，普通用户不需要手动下载。

Windows GPU runtime 使用 CUDA 13.0，仅适用于 Turing 或更新架构（计算能力 7.5+）且安装 R580+ 驱动的 NVIDIA 显卡。其他设备请选择 CPU 包，避免无效下载。
