## v1.2.0 新版本内容

本版本重点提升大批量视频下的识别性能与内存占用、重写合并编辑器、全面修复任务执行与报告查看过程中的卡顿，并修复一系列页面显示与数据明细问题。

### 新增与优化

- 识别引擎升级：
  - 候选筛选引入多尺度草图与 LSH 签名索引，候选检索更快更准。
  - 嵌入改为流式分批计算并复用帧缓存，支持可选半精度（FP16）CUDA 推理，大幅降低显存与内存占用。
  - 模型与索引改为资源池按需加载/释放，避免常驻占用内存。
  - 分段器加入方向感知聚合与在线趋势拟合，包含 / 被包含关系的判定更准确。
  - 新增运行指标统计（各阶段内存峰值、显存快照），便于排查资源占用。
  - 帧缓存升级至新结构，旧缓存自动重建。
- 合并编辑器重构：拆分时间轴、预览、播放、交互、草稿等 20 多个职责模块；时间轴支持虚拟化渲染与自适应宽度，大量片段不卡顿；新增高级设置对话框与预览编辑草稿交互。
- 全页面统一紧凑页头，结果 / 对比 / 合并 / 设置页面布局更紧凑，给内容更多可视空间。
- 结果页分页优化：默认每页 20 条（原 10 条），新增 100 条档位，页码改为紧凑数字按钮，表格获得更多可视空间。
- 设置页「重置」按钮改为文字按钮并增加确认提示，避免误触导致配置丢失。
- 运行环境首次下载对话框新增网络代理输入框，代理设置保存后供后续更新与模型下载复用。
- 用户可见日志本地化：运行、扫描、索引、比较、报告等阶段的日志统一为「中文(English)」双语输出，中英文用户均可直接阅读；供前端解析的机器协议行保持不变。

### 修复的问题

- 修复任务执行期间界面卡顿、无法切换页面：比较阶段逐帧回报进度导致前端高频整页重渲染，现已按时间节流回报进度，并始终放行明显跳变与最终进度。
- 修复进入结果页即解析大报告导致卡顿：初始不再自动读取报告，下拉框显示「选择报告文件」，仅任务完成时自动读取本次任务生成的报告。
- 修复对比视图重复读取报告文件导致卡死：对比页只读取内存中的帧匹配结果，不再重新解析报告。
- 修复报告读取 / JSON 解析在主线程执行导致界面冻结：改为在阻塞线程池中完成，主线程始终响应。
- 修复删除报告不生效：改为应用内两步确认后再删除对应报告文件。
- 修复近重复视频对不显示相似帧明细：余弦相似度的浮点精度残留被误判为百分比导致明细全部被过滤，现已正确归一化，近重复对可完整查看逐帧匹配。
- 修复结果总览页「比较结果」子页面底部被截断：分页按钮与结果表格现可正常滚动查看。
- 修复相似帧对比页与相同文件对比页底部被截断、无法滚动查看更多内容。
- 修复「新建任务」每次都重新扫描整个视频目录：视频目录未变化时直接复用已有扫描结果。
- 修复结果页 / 对比页切换时的首次卡顿：启动后空闲预加载各页面资源。
- 修复分析任务页英文「Create Task」等按钮折成两行、浪费空间：操作行按钮改为单行布局，英文标签不再换行。
- 修复设置页长英文参数标签折行而非省略：补全单行省略逻辑，超长标签正确显示省略号。
- 修复结果页分页、对比页「回到该帧」等英文按钮在窄布局下折行。
- 修正英文翻译用词（What's New、full workflow、fine-tune、Elapsed Time、Managed env 等），区分「关闭窗口(Close Window)」与开关「关闭(Off)」，并补齐网络代理、模型安装/重装、全选报告、播放器错误提示等此前缺失的英文。

## 下载建议

普通用户只需要下载一个与系统对应的应用包：

- Windows CPU 安装版（推荐大多数用户）：`Video_Similarity-v1.2.0-windows-x64-cpu-installer.exe`
- Windows GPU 安装版：`Video_Similarity-v1.2.0-windows-x64-gpu-installer.exe`
- macOS M 系列：`Video_Similarity-v1.2.0-macos-arm64-installer.dmg`
- macOS Intel：`Video_Similarity-v1.2.0-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：`Video_Similarity-v1.2.0-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：`Video_Similarity-v1.2.0-linux-x64-installer.rpm`

不想安装时，可以选择同平台文件名中带 `portable` 的便携包，解压后直接运行。
