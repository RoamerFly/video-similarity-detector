## 新版本内容

本版本重点完善视频合并时间线、网络下载体验和 Windows 构建稳定性。

### 新增与优化

- 重新设计合并时间线缩放，支持 0%–200% 精细调节、百分比输入和快速重置，长视频与短片段均可准确定位。
- 为视频片段增加时间线双端拖拽裁剪，并优化视频、音频片段的轨道排列与防重叠逻辑。
- 新导入的音频可按轨道自动连续排列，音频预览位置与最终导出时间保持一致。
- 新增 HTTP、HTTPS、SOCKS5 和 SOCKS5H 网络代理设置，可用于检查更新、下载安装包和下载离线 CLIP 模型。
- CLIP 模型下载支持缓存与断点续传，网络中断后可继续未完成的下载。
- 优化字幕编辑聚焦、自定义输出分辨率、预览窗口尺寸及设置页的小屏幕布局。

### 修复的问题

- 修复从托盘或隐藏状态退出时，关闭方式确认窗口可能不可见的问题。
- 修复紧凑窗口下设置页内容和离线模型安装区域可能被遮挡的问题。
- 修复部分视频、音频片段拖动或裁剪后发生同轨重叠、位置与导出结果不一致的问题。
- 改进 Windows CPU/GPU 构建脚本的进程锁定、依赖复用、错误码处理和并行构建稳定性。
- 改进 FFmpeg 运行时下载，在 curl 不可用或失败时自动使用 PowerShell 下载方式重试。

## 下载建议

- 大多数 Windows 用户建议下载 `windows-x64-cpu-installer.exe`。
- NVIDIA 显卡且需要 CUDA 加速的 Windows 用户请选择 `windows-x64-gpu-installer.exe`。
- 不希望安装时可下载对应的 `portable.zip` 便携版，解压后直接运行。
- 首次使用离线 CLIP 模型时，可在应用设置中直接下载；网络受限时可先配置代理，或手动下载 `clip-vit-base-patch32.zip`。
