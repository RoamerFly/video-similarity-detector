## v1.2.4 新版本内容

本版本集中修复合并视频页面的时间线交互、播放稳定性与分辨率预览问题，并深度优化合并导出时的内存占用和流畅度。

### 一、合并编辑器与时间线

- 视频、音频、文本片段均支持长按拖动、跨轨道移动和同轨道交换；拖动过程中显示实时浮动预览，交换完成后自动消除空洞并校准到连续时间线。
- 新增“一键对齐时间线”，可将视频线片段从后向前压紧，关联音频同步移动，避免出现无视频的空白时长。
- 时间线支持折叠/下拉隐藏；片段拉伸长度时提供即时动画反馈。
- 片段标题只显示不带后缀的文件名，移除冗余时长与装饰图案。
- 文本片段通过右键“属性”编辑内容、字号和颜色，并提供文字样式预览；文本属性不再占用输出检查面板。
- 音频片段新增右键“属性”，可调整音量等音频设置。

### 二、预览、全屏与分辨率

- 输出属性面板改为真实占用布局空间，预览区域会在面板打开时正确居中和自适应。
- 修复修改输出分辨率后预览框持续缩小且无法放大的问题。
- 全屏预览支持连续播放后续片段，底部新增播放进度条。
- 新增“模拟真实分辨率清晰度”：可选择当前视频线片段或指定时长进行计算，计算完成后可在“实时/已计算”视图间切换。

### 三、播放稳定性

- 修复后台重复创建多个视频/音频播放器、无法暂停以及偶发无声音的问题。
- 播放器切换、暂停和销毁统一协调媒体元素，减少后台解码器残留。

### 四、合并导出性能（重点）

- 对无重叠时间线使用低内存 concat 管线；仅在确有重叠时使用合成画布，显著降低长视频和多片段导出的峰值内存。
- 同一文件的视频与提取音频复用 FFmpeg 输入，避免重复打开和重复解码。
- 对静音音频不再探测、解码或延长输出时长；音频覆盖规则保持正确。
- FFmpeg 解码器、滤镜和编码器使用统一 CPU 线程预算，并为界面保留响应余量；后台进程降低优先级，减少导出时卡顿。
- 导出期间暂停预览媒体解码，进度事件与日志合并节流，降低主线程和内存压力。
- 视频元数据探测结果缓存，减少重复 I/O 和 FFmpeg 启动次数。

### 五、输入与兼容性修复

- 自定义宽度、高度、字号及其他数字输入支持 Backspace 清空后重新输入，不再强制保留最小值字符。
- 修复文本线被截断、分辨率切换布局错位等显示问题。

## 下载建议

普通用户只需要下载一个与系统对应的应用包：

- Windows CPU 安装版（推荐大多数用户）：`Video_Similarity-v1.2.4-windows-x64-cpu-installer.exe`
- Windows GPU 安装版：`Video_Similarity-v1.2.4-windows-x64-gpu-installer.exe`
- macOS M 系列：`Video_Similarity-v1.2.4-macos-arm64-installer.dmg`
- macOS Intel：`Video_Similarity-v1.2.4-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：`Video_Similarity-v1.2.4-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：`Video_Similarity-v1.2.4-linux-x64-installer.rpm`

不想安装时，可以选择同平台文件名中带 `portable` 的便携包，解压后直接运行。
