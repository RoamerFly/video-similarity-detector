## 新版本内容

本版本大幅提升大批量视频场景的稳定性与用户体验。

### 新增功能

- **右键重命名视频**：视频列表右键菜单新增"重命名"选项，支持单个或批量（多选模式）重命名视频文件，自动校验非法字符，重命名后同步更新扫描列表。
- **扫描状态持久化**：扫描视频后切换页面再切回，扫描结果和多选状态不再丢失。

### 优化

- **视频元数据探测分批处理**：视频数量较多时（50+），自动拆分为多批处理，单批失败不影响其他批次，整体更健壮。
- 每批使用独立临时 JSON 文件传递路径，彻底规避 Windows 命令行长度限制。
- 发送 metadata-progress 事件供前端展示元数据读取进度。

### 修复的问题

- 修复 Windows 下视频数量多时 "文件名或扩展名太长 (os error 206)" 导致无法读取视频信息的问题。
- 修复页面切换后扫描进度和多选状态丢失的问题。
- 修复大型任务把完整配置和大量视频路径写入 Python 启动命令，导致 Windows 报错的问题。

## 下载建议

- 扫描大量视频或需要重命名视频的用户建议升级。
- 大多数 Windows 用户建议下载 `windows-x64-cpu-installer.exe`；NVIDIA 显卡且需要 CUDA 加速时请选择 `windows-x64-gpu-installer.exe`。
- 不希望安装时可下载对应的 `portable.zip` 便携版，解压后直接运行。
- `.sig`、`latest.json` 等文件用于自动更新和签名校验，普通用户无需单独下载。
